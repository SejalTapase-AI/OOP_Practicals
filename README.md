# Practical 3 – Operator Overloading

## Topic
Operator Overloading using Default and Parameterized Constructors

## Description
This practical demonstrates operator overloading in C++ using default and parameterized constructors.

The program represents a simple real-world situation where marks from two assessments are stored in separate objects. The `+` operator is overloaded to add the marks stored in the two objects and calculate the total marks.

The program also takes marks as input from the user.

## Concepts Used
- Classes and Objects
- Default Constructor
- Parameterized Constructor
- Operator Overloading
- Member Functions
- User Input

## Real-World Application
The program models the process of combining marks from two different assessments. This shows how operator overloading can be used to perform meaningful operations on objects.
